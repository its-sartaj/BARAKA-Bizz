# BARAKA Bizz. — Luxury Apparel & Artisanal Wear

BARAKA Bizz is a modern, high-end e-commerce web application for luxury apparel and handcrafted artisanal fashion. Built with React 19, TypeScript, Vite, and Tailwind CSS.

## 🌟 Features

- **Luxury Catalog**: Curated collections (Men, Women, Artisanal, Accessories) with dynamic filtering and sorting.
- **Product Details & Quick View**: High-resolution imagery, size selection, fabric details, and customer reviews.
- **Cart & Wishlist Management**: Seamless slide-out cart drawer, persistent storage, and promotional coupon support.
- **Direct Checkout**: Streamlined multi-step checkout workflow with order summary and tracking.
- **Admin Dashboard**: Secure management interface for catalog updates, inventory tracking, and order fulfillment.
- **Modern Responsive Design**: Editorial typography, smooth micro-interactions with Framer Motion, and mobile-first layout.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Motion (Framer Motion)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/its-sartaj/BARAKA-Bizz.git
   cd BARAKA-Bizz
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🔒 Security & Privacy

- No sensitive credentials, secrets, or API keys are committed to version control.
- All environment configurations should be defined in `.env.local` (ignored via `.gitignore`).
- Mock authentication and order transactions run client-side with no persistent remote attack surface.
